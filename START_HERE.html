Open the data in Power BI

  1. Open Power BI Desktop. If needed, get it from the official Microsoft page.
  2. Choose Home → Get data → More. Search for Parquet and click Connect.
  3. Open the data folder next to this page. Right-click Alcedo_atthis.parquet and choose Copy as path (on older Windows, hold Shift while right-clicking). Paste the location into Power BI and remove surrounding quotation marks.
  4. Choose Transform Data. Set year to Whole number. For decimalLatitude and decimalLongitude, use Change Type → Using Locale → Decimal number → English (United States).
  5. Click Close & Apply. Add a column chart. Drag year to the X-axis and gbifID to the Y-axis. Set the Y-axis aggregation to Count.
  6. Save your report. You can now filter years and explore the data.

These numbers count records. They do not estimate the kingfisher population. All records in this extract have country code NL.
