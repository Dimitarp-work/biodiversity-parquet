# Assessment findings and limitations

Assessment progress — 16 October 2026
This assessment describes the Alcedo atthis extract: 429,646 occurrence records and 50 variables. The verified descriptive analysis, variable dictionary, privacy screening and conceptual model are filled in. Approximately 70% of the substantive sections are drafted; this is not a grading claim. Group agreement on the project question, target, final model inputs and success criteria, plus final review, remains outstanding. Existing group entries and completed classification tables have been preserved.

Parquet is a structured tabular dataset. All columns were preserved as text on export; classifications below refer to meaning, not physical storage. Empty source fields became NULL. R may display these as NA.

Classification conventions: numeric identifiers remain nominal. taxonRank is treated as an ordered hierarchy. month is cyclic, so a numerical average is only a descriptive summary. Alphabetic permits spaces and separators; alphanumeric means mixed text. Fully empty fields are classified by intended meaning. No genuine Boolean field is present.

Verified on all 429,646 rows: 21,482,300 cells; 7,265,072 NULL cells (33.82%); 50 variables; zero exact duplicate rows and zero repeated gbifID values. This does not rule out multiple records of one real-world event. Eleven datasets contribute records. Latitude, longitude and year have no missing or invalid numeric values.
Source: GBIF occurrence download, DOI https://doi.org/10.15468/dl.5kx93n (18 March 2026). Its verified filters are HUMAN_OBSERVATION, country NL, status PRESENT and years 2010–2025. The species extract additionally selects speciesKey 2475532. Sampling design is not established: combining 11 datasets does not prove a formal multiple-sampling design. The existing ticks should be understood as multiple sources, not proof of random sampling. Per-column missing counts and reproducible calculations are in the repository assessment/results folder.

NULLs are excluded from distinct counts and frequencies. Empty columns have zero observed distinct values and no mode. Each frequency cell shows one representative value and its count; ties are reported and the lexicographically first tied value is shown. Long values are shortened here; full values are retained in frequencies.csv. The table reports stored values before numeric conversion.

Statistics use valid, non-NULL numeric values with sample sizes in numeric_summary.csv. All non-NULL values in the 12 numeric measurement/calendar fields parsed successfully. Empty elevation/depth fields have unavailable statistics. IDs and categorical codes are excluded from averages. Calendar means are descriptive only, particularly for cyclic month/day.

Variable: decimalLatitude; n=429,646; no missing values. A 40-bin histogram shows a dominant peak around 52° and secondary geographic peaks, so strict unimodality is not claimed. Sample skewness is +0.1888: mild positive skew. Histogram appearance depends on binning and observation effort, not only bird distribution.

Quartiles use linear interpolation (NumPy quantile method='linear'). The fourth quartile entry is interpreted as the 100th percentile/maximum. Standard deviation uses the sample convention (n−1). Values are in decimal degrees, not metres.

The 1.5×IQR rule yields fences of 50.775° and 53.375°; 5,617 records (1.31%) fall strictly outside them. These are statistical flags, not automatic deletion rules. One record, gbifID 3028405533, has latitude 47.97523 and longitude 3.31361 despite countryCode NL; its source flag includes COUNTRY_COORDINATE_MISMATCH. It requires source verification. All records are retained.

Both coordinates are complete and numeric for n=429,646. Sample covariance(latitude, longitude)=0.093459 degrees²; Pearson r=0.2284 and Spearman rho=0.1888. The weak positive association coexists with marked spatial clustering. Neither a deterministic monotonic relationship nor a single linear model adequately describes the geography. No causal conclusion is supported.

This is an exploratory reference analysis using decimalLatitude, not a selected prediction target. A group-agreed target is still required for the final modelling assessment. Pearson correlations use pairwise valid observations; counts are shown. Spearman results are supplied in correlations.csv. Interpretation bands here are |r|<0.1 negligible, <0.3 weak, <0.5 moderate, otherwise strong; these are descriptive conventions. Calendar variables need cyclic interpretation. Four empty numeric fields have no estimable correlation.

Definitions and intended limits are based on GBIF field documentation (https://techdocs.gbif.org/en/data-use/download-formats) and Darwin Core terms (https://dwc.tdwg.org/list/), interpreted for this extract. Dataset-specific selection constraints are distinguished from universal value limits. Text encodings and identifier syntax do not make identifiers numeric measurements.

Y identifies direct person-related fields (recordedBy, identifiedBy and rightsHolder). Y* means potentially identifying through linkage: record identifiers and observation locations/times can be associated with a named observer. N means no direct personal content is intended by the field, not an assertion of anonymisation. No explicit special-category field was identified; free text and linked records still require contextual review. This is a screening assessment, not a legal compliance determination. Reference: GDPR Articles 4 and 9, https://eur-lex.europa.eu/eli/reg/2016/679/oj/eng/.
Ecological sensitivity is distinct from personal data: precise bird locations can be sensitive even without person identifiers. Prefer aggregated outputs for wider reporting and preserve original attribution. Licences: 420,734 CC_BY_NC_4_0 records; 8,880 CC_BY_4_0; 32 CC0_1_0. Do not assume the combined data is unrestricted for commercial reuse. Retain the licence, rights holder and dataset identifiers, and cite the GBIF download DOI.

This table describes intended domains, not just observed minima and maxima. Latitude is bounded by −90/+90 and longitude by −180/+180. Day/month bounds require calendar checks. Non-delimited means no fixed allowed range or finite list established here; formatting rules may still apply. Taxonomic names remain text. Country, record basis, status, rank, licence and processing flags use vocabularies; the full permitted vocabulary is broader than the values seen in this extract. year=2010–2025 and speciesKey=2475532 are selection constraints, not universal domain bounds. This is a proposed conceptual model for the occurrence-record system. Physical denotes the measured location/count property; informational denotes identifiers, classifications, metadata or descriptions. Continuant denotes an enduring entity; occurrent denotes an observation, identification or processing event. A property recorded about an event is marked occurrent. Alternative ontology choices should be agreed consistently by the group.

The diagram represents data provenance and associations, not a proven causal graph. An organisation publishes a dataset; the dataset contains occurrence records; each occurrence describes an observation of an identified taxon at a location, linked to observer attribution and media where supplied.
Causal hypotheses: recorded observations may reflect true bird presence, habitat, weather, season, observer effort and detectability. Available: observation location/date, reported individual count (partly missing), source dataset and coordinate uncertainty (partly missing). Unavailable as direct measured predictors: survey effort/duration, non-detections, habitat quality, weather and detectability. No numerical 'percentage of causal coverage' is asserted because the causal-factor universe is not fixed. Presence-only, effort-biased records cannot establish population abundance or causal environmental effects.
